# Mobile Layoutkorrektur

Dieses Update ersetzt ausschließlich assets/css/style.css. Keine HTML-Dateien, Bilder oder Texte werden überschrieben. Die neue Datei direkt im bestehenden Ordner assets/css/ in GitHub hochladen und Commit changes speichern. Eigene Änderungen an deiner style.css vorher sichern.

Nach der Veröffentlichung auf dem Handy die Seite neu laden. Falls noch die alte Ansicht erscheint: testweise die Website in einem privaten Browserfenster öffnen. GitHub Pages und Browser können ältere CSS-Dateien noch kurz zwischenspeichern. Alternativ in deinen HTML-Dateien den Stylesheet-Link mit einer Versionskennung ergänzen, z.B. style.css?v=mobile-20261001.

Überarbeitet: kompakter Header mit Menü auf derselben Zeile auch bei schmalen Displays; kleinere flexibel skalierende Überschriften; einspaltiger Einstieg bis 760px; Bilder ohne feste übergroße Höhen; Bildunterschrift im normalen Fluss; sichere Umbrüche für lange Texte/E-Mail-Adressen; Portraits mit geeignetem Hochformat; persönliche Fotos in Galerien auf Handys vollständig sichtbar; größere Formularschrift, passendere Abstände und Touchflächen; kompaktere Karten, Footer und Prozessdarstellung.

Desktop bleibt unverändert. Teamreihenfolge, Bildnamen, Profilgalerien, Kartenaktivierung und Demoformulare bleiben erhalten.

Die veröffentlichte CSS-Datei wurde mit der lokalen Version abgeglichen. Eine automatische visuelle Browserprüfung war in dieser Umgebung nicht möglich. Bitte Startseite, Teamprofil und Kontakt auf deinem Handy prüfen. Für konkrete verbleibende Probleme Screenshots und Gerät beziehungsweise Browser nennen.
